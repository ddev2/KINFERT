# Manual screenshots

This folder holds the screenshots used by [`../KinFert-Manual.md`](../KinFert-Manual.md).
The manual already references each file by name; drop a PNG with the matching
name here and it appears automatically (on GitHub and in local Markdown
previews).

## How to capture them

- **Format:** PNG (lossless — keeps the text crisp).
- **Partial is fine:** crop each shot to just the window or option group named
  below; you do not need the whole screen.
- **Keep them modest in size** (they are committed to the repository). If a shot
  needs to be scaled in the manual, the reference uses an `<img width=…>` tag.
- **Naming:** lower-case, hyphenated, exactly as listed below.
